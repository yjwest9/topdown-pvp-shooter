# 탑다운 군인 캐릭터 그림: Kenney 대신 쓸 수 있는 것 (조사: 2026-10-15)

목표: 홈 화면의 "어두운 택티컬 실루엣"(실제 비율, 헬멧·고글·방탄조끼)과 어울리는 인게임 탑다운 캐릭터.
조건: 위에서 본 시점, 소총/저격총/권총/재장전 포즈, Google Play 배포 가능, CC0 우선, 원작(스페셜솔져) 그림 금지.

> 라이선스는 각 에셋 **본인 페이지**에서 직접 확인했다. itch.io 유료 팩은 대부분 페이지에 라이선스 문구가 없다. 이런 팩은 "불명확"으로 표시했다(구매 전에 작가에게 물어봐야 함).

## 5. 대안: 홈 화면처럼 코드(벡터)로 탑다운 실루엣 그리기

| 항목 | 평가 |
|---|---|
| 청회색 돌바닥에서 잘 보이나 | 몸을 아주 어둡게 하면 회색 바닥에 묻힘. **얇은 밝은 테두리(림 라이트) + 팀 색 어깨/헬멧 띠 + 총은 더 밝은 회색**으로 해결 가능. 색을 코드에서 바로 바꿔 보며 맞출 수 있음 |
| 홈 화면과 통일감 | 같은 방식, 같은 색 토큰을 쓰니까 가장 잘 맞음 |
| 포즈 | 위에서 보면 헬멧(원) + 어깨(타원) + 팔 + 총만 있으면 됨. 소총/저격총/권총/재장전은 팔 각도와 총 길이만 바꾸면 되고, 무기 데이터(`balance.dart`의 무기 한 줄)에서 총 길이를 받아 그리면 됨 |
| 용량·라이선스 | 이미지 0KB, 라이선스 문제 없음 |
| 작업량 | 포즈 5개 × 1인 기준 하루~이틀. 캐릭터 4종은 색·헬멧 모양만 바꾸면 됨. 걷기 애니메이션은 다리 흔들기 정도로 단순하게 |
| 위험 | 그림 품질이 직접 그린 실력에 달림. 프레임마다 그리는 비용은 Flame에서 `Picture`로 미리 구워 두면 됨(맵 타일을 한 장으로 미리 그린 방식과 같음) |

## 6. 추천 Top 3

1. **코드로 그린 탑다운 실루엣**: 홈 화면과 같은 스타일이고, 라이선스 걱정이 없고, 파일 크기도 0이다. 맞는 CC0 세트가 없기 때문에 CC0 정책을 지키면서 "택티컬" 느낌을 낼 수 있는 유일한 길이다. 스타일은 Door Kickers 2를 참고한다.
2. **gamedeveloperstudio 탑다운 군인 팩($15)**: 작가 약관이 명확하다(상업용 가능, 크레딧 불필요). black camo가 있고 SVG 부위가 들어 있어서 어둡게 고치기 쉽다. 재장전·저격총이 페이지에 없으니 직접 만들어야 할 수 있다. ([itch](https://gamedeveloperstudio.itch.io/top-down-animated-soldiers-game-character-pack), [license](https://www.gamedeveloperstudio.com/license.php))
3. **Riley Gombart Survivor (CC-BY 3.0)**: 무료이고 소총·권총 재장전 프레임까지 갖춘 유일한 탑다운 세트다. 다만 크레딧이 필요하고 민간인 복장 1명뿐이라, 색을 어둡게 하는 정도로만 고칠 수 있다. 1번을 만들 때 **포즈 참고용**으로 쓰기 좋다. ([OGA](https://opengameart.org/content/animated-top-down-survivor-player))

Aviala·pzUH는 값은 싸지만 페이지에 라이선스 문구가 없다. 작가에게 서면 답을 받기 전까지는 보류한다.
